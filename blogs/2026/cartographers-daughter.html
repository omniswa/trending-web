Text and links

Body copy can include bold text, italic text, highlighted text, removed text, and small print. Use an internal link to point readers to related posts, and an external link to cite sources. Keep link text descriptive rather than “click here”.

A subsection heading

Use one h1 per page, then h2 for sections and h3–h4 for sub-points. Never skip levels. Press Ctrl + F to find text on the page.

  return text
    .toLowerCase()
    .trim()
    .replace(/[^a-z0-9]+/g, '-')
    .replace(/(^-|-$)/g, '');
}
